PDF測定Q範囲の設計

格子定数と測定範囲から，主要な低角Bragg反射の収録可否とPDFの実空間分解能を確認する計算ツールです。

PDF測定ツール
試料と測定条件

Q範囲
—
Δr ≈ π / Qmax
—
代表反射の収録数
—

—

立方晶の代表的な低角反射（幾何学的位置）
反射 d [Å] Q [Å−1] 2θ [°] 判定

使い方

格子定数 a，X線波長 λ，測定するQ範囲を入力してください。初期値は，a = 16.99 ÅのZIF-8と，λ = 0.496054 Åの測定を想定しています。表の「収録」は，反射位置がQmin以上かつQmax以下にあることを意味します。

例えばQmin = 0.70 Å−1では，ZIF-8の(110)反射は低角側で失われますが，(200)以降の代表反射は収録範囲に入ります。Qmaxを大きくすると，PDFの概算実空間分解能 Δr ≈ π/Qmaxは小さくなります。

計算方法と注意

d = a / √(h2 + k2 + l2)
Q = 2π / d
2θ = 2 sin−1(λ / 2d)
Δr ≈ π / Qmax

このページは，立方晶の格子から計算した反射位置だけを示します。構造因子，原子散乱因子，反射強度，装置分解能，検出器の受光効率，バックグラウンドは考慮していません。そのため，「収録」は実測で明瞭なピークが得られることを保証するものではありません。

PDFの実際の品質は，QminとQmaxだけでなく，補正・規格化，バックグラウンド処理，測定時間，統計精度，および高Q側のS/Nにも依存します。PDF解析で用いる規格化関数の定義によって式の表記は異なりますが，このページではQ範囲設計の目安としてΔrを表示しています。
